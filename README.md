# Telegram-Бот для генерации Чеков

Бот обрабатывает заявки пользователей через Telegram, создавая топики в мультигруппе для общения между пользователем и администрацией. Он предоставляет:
- Приветственное меню с кнопками «Информация», «Цены», «Оставить заявку»
- Автоматическое создание топика в группе при оформлении заявки
- Поддержку массовой рассылки сообщений (текст, фото, видео, документы и т.д.)

## Переменные окружения (.env)

Создай в корне проекта файл `.env` с данными:

```
POSTGRES_NAME=your_db_name
POSTGRES_HOST=your_db_host
POSTGRES_PORT=your_db_port
POSTGRES_PASSWORD=your_db_password
POSTGRES_USER=your_db_user

BOT_TOKEN=your_bot_token
BOT_GROUP_ID=your_bot_group_id # с минусом
BOT_ADMINS=[your_admin_ids] # int
```

Заполни значения согласно своей инфраструктуре, чтобы бот мог корректно подключаться к базе данных и Telegram API.
